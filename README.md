# Trabajo Práctico 2 — Informática General

## Descripción del proyecto

Trabajo Práctico 2 de Informática General, carrera de Artes Multimediales (UNA). Consiste en un sitio web documental e interactivo sobre la producción, el contexto y la trayectoria del colectivo artístico "Tucumán Arde" (1968). El proyecto está desarrollado con HTML, CSS y JavaScript, integrando un framework CSS y una librería JS, aplicando los contenidos teóricos y prácticos vistos durante la cursada.
